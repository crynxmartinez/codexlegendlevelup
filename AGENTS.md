# Project instructions

## Card artwork and frame consistency

Current approved layout: [rounded frame v3](docs/design/card-frames/v3/STANDARD.md), approved 2026-10-11. It supersedes the v1 title, labels, power and defense components described below. Regional cloth: yellow Luzon, blue Visayas, red Mindanao. Use the shared rounded Baybayin inset; preserve the v1 historical references.

Before creating, editing, reviewing or exporting card frames, read [the approved card frame standard](docs/design/card-frames/v1/STANDARD.md) and inspect its canonical master images. This is the user's saved standard from 2026-10-08.

Use Salendagao's defense component for all Units/Forces with defense. Sentries have no power display. Codex uses a plain red gem with no book or number. The latest red Pah is the Persona master. Follow the documented type-gem and archipelago colors. Original uploads may contain superseded details; the standard records those exceptions.

Preserve originals and v1 masters; create versioned revisions. Do not replace live assets or change card rules merely because artwork is being saved.
