# Original game audio

These 33 PCM WAV files are original procedural sound designs generated by
`tools/generate-audio.py`. They contain no sampled third-party recordings.
Each of eleven common cues has three variations. Runtime Web Audio synthesis
remains the fallback while the assets load. Music and ambience are generated
by `src/ui/sfx.ts` and are artistic motifs, not traditional recordings.

Regenerate with: `python tools/generate-audio.py`.
