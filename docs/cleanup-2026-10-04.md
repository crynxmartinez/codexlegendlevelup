# Unused code and asset cleanup — October 4, 2026

## Result

The initial compiler audit reported 110 unused declarations across 25 files.
Those declarations and newly exposed dead callers have been removed. Necessary
callback parameters retain their positions with underscore names. Calls that
construct test positions still execute even when their return value is unused.

Public assets: **850 files / 147,371,084 bytes** before; **828 files /
137,547,229 bytes** after. Reduction: **9,823,855 bytes (9.37 MiB)**. This measures
published files, not the bytes a player downloads at startup.

## Prevention

- `noUnusedLocals` and `noUnusedParameters` are enforced by TypeScript.
- `npm run audit:assets` checks catalogue images, all three card resolutions,
  cue variations, cutscene naming, region maps and fixed runtime paths.
  Missing files or unknown public files fail the check. Filenames are checked
  case-sensitively even on Windows.
- The quality workflow runs the asset audit and production build.
- The current README replaces stale Angel/Energy/spreadsheet instructions.
  Earlier documentation remains explicitly historical.
