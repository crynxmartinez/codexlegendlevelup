# Three regional tutorial decks — approved plan and local implementation

2026-11-16 implementation status: the approved lists are connected to the regional tutorial path. Normal starter decks and saved decks are unchanged. See [IMPLEMENTATION.md](IMPLEMENTATION.md) for the changes and acceptance criteria, and [VERIFICATION.md](VERIFICATION.md) for automated results, built-in-browser evidence and remaining coverage gaps. Publication is recorded in Git history; live deployment requires separate verification.

The proposal below is retained as its historical design record. Its original status was: “Design plan only. These lists are not connected to live play and are not changes to saved decks or normal starter decks.” References below to proposed lists, future implementation and validation describe that original planning stage, not the current implementation status.

Each draft has 50 main cards: 15 Level 1 Units, 12 Level 2 Units, 6 Level 3 Units, 12 Forces, 3 Actions and 2 Sentries. The two Codex are outside the 50; the starting Persona is selected from the main list, not added as a 51st card.

Every main card except the Sentry has three copies. The Sentry has two. The only deck-construction exception is the existing tutorial two-Codex profile. Names, art, base statistics and other card-type effects are unchanged.

This keeps the currently approved tutorial effects. L3 State-gated skills are removed; ordinary L3 skills remain and require explicit guidance. Further removal or replacement of these skills needs separate approval.

## Common learning roles

- L1: support 6 copies, arrival 6, attacker 3. L2: support 6, arrival 3, attacker 3.
- Support: +3k at L1 / +5k at L2 to that supporter, once in its normal contribution, that attack only.
- Arrival: +3k / +5k after normal or special call, until the current turn ends.
- Attacker: +3k / +5k while attacking, that attack only.
- Attack Codex: active Persona +5k while attacking. Barrier Codex: active Persona +1k per own broken Barrier, either turn. Existing switch windows remain.

These are matching lesson structures, not a claim of equal match strength or proven beginner comprehension.

## Teaching and implementation plan

1. Keep chapter progress and the current five-chapter structure. Use a single selected training region to choose these named presets; no new inventory, unlock or deck-building task.
2. Audit each prepared lesson dependency before swapping its list. First Battle currently relies on Nanolay as an Ally, Kalimangalnuk as Persona, Sinag as blocker and a particular Action; do not blindly point that fixture at a list lacking its scripted cards. Refactor teaching references to known role IDs and equivalent legal outcomes, or document a deliberate prepared-lesson exception.
3. Teach common roles before regional skills. Preserve manual Continue, legal-action highlights and the existing hand/Barrier layout. Do not expose a new Sanib, Sipol, Offer or placement decision without explaining its cost and destination first.
4. Keep the regional Sentry and Action unchanged. Show a bounded regional introduction before free Practice Duel: Luzon recovery plus Sipol placement; Visayas Heart/Sanib plus Bituon token result; Mindanao recovery plus optional Offer cost. Do not require optional boss skills to win or silently auto-decline them in free practice.
5. Wire Practice Duel and its opponent to the same named preset/profile boundary. Guided encounters may arrange hands and draws; free practice uses the normal shuffle and choices.
6. Keep these presets outside normal saved decks and production starters. Explicitly map chosen card IDs to roles so catalogue reordering cannot alter the lesson. Normal play retains five Codex.
7. Verify each list, all chapter paths, both sides, all nine regional practice pairings, modifier cleanup, hidden information, progress/replay and return to normal AI. Review desktop and mobile landscape in the built-in browser only. Compare actual effect-prompt counts, stalled hands and match length before claiming equal accessibility.

## Remaining design decision

The approved policy removes only State-gated L3 skills. It does not make all boss cards vanilla. The safest next design review is the actual L3/Action/Sentry text above. If first-time learners still struggle, propose a separately approved tutorial-only L3 simplification; do not implement one implicitly. Forces also retain their normal response abilities.

## Validation performed for this plan

Each proposed list was checked against the current selectable catalogue, the engine tutorial deck validator and normal deck checks with only the expected two-versus-five Codex exception. All three contain exactly 50 main cards, 12 Forces, 2 Sentries, no card over three copies and all six basic role/level combinations.
This is list validation only: no live interface or gameplay changed, no automated match simulation or new browser playtest performed for these proposed lists, and no push/deployment.
