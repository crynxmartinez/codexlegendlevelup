# Creator-supplied music

These audio-only files were extracted on 3 October 2026 from the three local MP4
files supplied by the owner. The AAC stereo stream is copied into an M4A container
with fast-start metadata. No video remains and no additional lossy encoding was
performed. Originals were left unchanged.

| Song | Original MP4 bytes | Audio M4A bytes |
| --- | ---: | ---: |
| Journey of Hearts | 5,875,351 | 3,147,700 |
| Break Those Limits | 6,980,050 | 2,606,952 |
| Break the Chains | 6,227,353 | 2,622,349 |
| Total | 19,082,754 | 8,377,001 |

56.1% smaller in total. Source audio: AAC LC, 44.1 kHz, stereo, approximately
128 kbit/s. The game streams the selected song; it does not preload the library.

Scene assignments are in `src/data/soundtrack.ts`. Title and learning use Journey
of Hearts; victory uses Break Those Limits. All three are selectable from Music
& credits. Battles retain the existing quiet procedural score because no separate
instrumental exports were supplied.

The owner must supply final composer/performer/music-tool credits and confirm
contest rights. These files are not asserted to be public-domain assets.
